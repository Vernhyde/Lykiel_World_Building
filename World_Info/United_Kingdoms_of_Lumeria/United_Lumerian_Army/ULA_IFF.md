## **Arcane Layer** 

Rune-Tag which works as a Mana Responder for Seers and others to use along with the drone network.

If the Tag which is attached to individuals detects a change of state it will either change its frequency or fail altogether (like death, incapacitation, possession, Illusions) Seers would be able to spot a difference which can be used to prevent walking into a trap or Search and Rescue as well as giving a tiny bit of info whether they are alive or not.

Like RF systems though there is a system or Defensive and Offensive Systems to Detection and Obfuscation 

So you can jam/blind a seer/drone.

Rune Tags should be set up with dog tags so essentially it's Personal info, Mana info, rune tag IFF

- Main Tag  
  - First Name  
  - Last Name  
  - ID Number  
  - Blood Type  
  - Species (Hybrids will have more than one)

- Mage Tag  
  - Mage Type (if Any)  
  - Mana Octave (if Any)  
  - Mana Capacity (if Any)  
  - Notes (Such as Lycanthropy or Mutations)

Additional Tags may be added if needed for additional notes of Mage Tag may be used only for notes if not magically inclined

- Rune Tag  
  - Status (Fluctuates slowly and is detectable)  
  - Kingdom  
  - Unit (Detectable but usually not enabled except for Officers, NCOs, and Special Units)  
  - Rank (Can be modified without New Tags)

Removal of the Rune Tags prevents all Magical forms of IFF detection for both friends and foe (i.e., you might get shot if a Seer Misidentifies) but also allows the user to not always be tracked for various reasons.
